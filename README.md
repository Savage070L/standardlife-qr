# Standard Life — Генератор QR-кодов для визиток

Web-приложение для генерации QR-кодов с контактными данными (vCard).
Открывается в браузере, никаких зависимостей ставить не нужно — всё встроено в один `index.html`.

## Возможности

- **Одиночная генерация**: заполнить форму (ФИО, должность, регион, адрес, email, телефоны) → получить QR.
- **Массовая генерация из XLSX**: загрузить файл в формате «Новые Заявки» → получить русскую и казахскую версии для каждой строки и скачать архивом.
- Поддержка добавочных номеров (после `:` в Excel или в отдельном поле формы).
- Локализованные NOTE и ORG для русского и казахского.

## Использование

Открыть `index.html` в браузере или зайти на опубликованную страницу GitHub Pages.

## Стек

- Чистый HTML/CSS/JS, без сборки.
- Встроенные библиотеки: `qrcode-generator`, `SheetJS xlsx.mini`, `JSZip`.
